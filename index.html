RPG Maker MZ Save Editor

Static, offline-friendly LZString round-trip editor for .rmmzsave / .rmmzdata payloads. Always keep backups.

Upload

Primary: drop slot saves (file*.rmmzsave), plus optional global.rmmzsave / config.rmmzsave.

Compressed blobs are decoded with the same lz-string Base64 codec that RPG Maker MZ ships in rmmz_managers.js.

Recommended helpers: Actors.json, Items.json, System.json, MapInfos.json
